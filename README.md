# ماسة الشام للحوالات المالية

Masa Al-Sham Financial Transfers — Next.js Web App

## بيانات الشركة
- الاسم: ماسة الشام للحوالات المالية
- English: Masa Al-Sham Financial Transfers
- تأسست: 2020
- الموقع: Baghdad, Iraq
- الهاتف وWhatsApp: +9647772073950
- الدول: سوريا، مصر، لبنان، تركيا فقط

## تشغيل المشروع
```bash
npm install
npm run dev
```
ثم افتح `http://localhost:3000`.

## ملاحظة مهمة قبل الإنتاج
النسخة الحالية تحتوي على واجهة وإدارة تطويرية، وتخزن البيانات في ذاكرة الخادم. قبل استخدامها في الإنتاج يجب ربط قاعدة بيانات دائمة وإضافة Authentication وصلاحيات للمدير وحماية API وRate Limiting.

## رسالة WhatsApp
عند إنشاء طلب حوالة، يتم تجهيز رسالة WhatsApp بالترتيب الثابت:
1. رقم الطلب
2. تفاصيل الحوالة: المبلغ، طريقة الاستلام، الدولة، مدينة المستفيد
3. بيانات المرسل: الاسم، الهاتف
4. بيانات المستفيد: الاسم
5. الملاحظات
6. تنبيه المراجعة والتأكيد

لا يتم اختراع أسعار صرف أو أرقام تراخيص أو عناوين تفصيلية أو أسماء محافظ غير مقدمة من الشركة.
